# CodeOrbit Tech – Task 2: Sales Data Analysis

## Objective
Clean a sales dataset and use Python to summarize sales performance by product and region.

## Files
- `sales_dataset.csv` — small illustrative sample dataset.
- `sales_analysis.py` — data cleaning, summary statistics, grouped analysis, and chart generation.
- `requirements.txt` — required Python libraries.
- `short_report.md` — brief report template/summary.

## Important dataset note
The CSV included here is a **sample dataset created for demonstration**, not an official dataset supplied by CodeOrbit Tech. If your internship instructions provide a dataset, replace this CSV with that file and ensure its column names match the script (or update the script accordingly).

## Run the project
1. Install Python 3.
2. Open a terminal in this repository folder.
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Run:
   ```bash
   python sales_analysis.py
   ```

The script creates `sales_analysis_output.csv` and `revenue_by_product.png` in the same folder.
