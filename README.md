# CodeOrbit Tech – Task 2: Sales Data Analysis

## Objective
Clean a sales dataset and summarize sales performance by product and region using Python.

## Files
- `sales_dataset.csv` — illustrative sample dataset (12 rows).
- `sales_analysis.py` — data cleaning, summary statistics, grouped analysis, and chart generation.
- `sales_analysis_output.csv` — cleaned output for the currently included sample dataset.
- `revenue_by_product.svg` — viewable chart of revenue by product.
- `requirements.txt` — required Python libraries.
- `short_report.md` — report with sample-run results and methodology.

## Important dataset note
The included CSV is a **sample dataset created for demonstration**, not an official dataset supplied by CodeOrbit Tech. If the internship instructions provided a required dataset, replace this CSV with that file and ensure its column names match the script (or update the script accordingly).

## Run the project
1. Install Python 3.
2. Open a terminal in this repository folder.
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Run:
   ```bash
   python sales_analysis.py
   ```

The script creates `sales_analysis_output.csv` and `revenue_by_product.png` in the same folder. The SVG chart included in the repository is a convenient preview generated from the currently included sample data.
